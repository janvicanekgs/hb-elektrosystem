# Osnova schůzky s klientem

## 1. Ukázka webu (5–10 min)
- Otevřít na mobilu, projít HP od shora dolů
- Ukázat menu → Služby → KNX, MaR
- Ukázat stránku Reference (filtrování)
- Zdůraznit: tohle je jen začátek, fotky a texty doplníme podle reality

---

## 2. Jak to celé funguje – jednoduše (5 min)

**Wix dnes:**
- Klient platí Wixu každý měsíc za pronájem prostoru
- Design je zamčený ve Wixu, nelze vzít jinam
- Doménu (hbelektrosystem.cz) vlastní klient ✓

**Nový web:**
- Soubory jsou naše – nikdo nám je nemůže vzít
- Hosting = **Netlify**, zdarma
- Klient platí jen doménu (~200 Kč/rok, jako dosud)

---

## 3. Přechod z Wixu – co to obnáší (3 min)

1. Dokončíme web (zbývají 2 servisní stránky)
2. Nahrajeme soubory na Netlify (přetažení složky, 2 minuty)
3. V administraci domény změníme nameservery na Netlify
   → trvá pár hodin, pak web běží na hbelektrosystem.cz
4. Wix předplatné klient zruší nebo nechá doběhnout

**Celkové náklady po přechodu:** ~200 Kč/rok (pouze doména)

---

## 4. Správa webu do budoucna (2 min)

- Nová reference = přidám jeden blok textu a fotku
- Úprava textu nebo kontaktu = editace jednoho souboru
- Klient nemusí nic dělat, vše vyřídíme spolu

---

## 5. Případné otázky klienta

**„Bude web fungovat, když ty nebudeš dostupný?"**
→ Ano, web běží sám na Netlify bez zásahu. Úpravy mohou počkat.

**„Co když Netlify zkrachuje?"**
→ Soubory máme uložené, během hodiny spustíme web jinde.

**„Jak přidám novou referenci sám?"**
→ Zatím to bude přes tebe. Pokud bude chtít přidávat sám, dá se přidat jednoduché admin rozhraní nebo přejít na WordPress.

**„Kolik mě to bude stát?"**
→ Doména ~200 Kč/rok. Za úpravy webu se domluvíte individuálně.
